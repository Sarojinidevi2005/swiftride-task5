# 🚖 SwiftRide – Taxi Booking Website (Task-5)

## 📌 Project Overview

SwiftRide is a modern, responsive Taxi Booking Website developed as part of the **ApexPlanet Software Pvt. Ltd. Web Development Internship – Task 5**.

The project provides an intuitive interface for users to explore taxi services, book rides, view vehicle categories, and contact the company. It is designed with a clean UI, responsive layout, and interactive JavaScript features.

---

- ✅ Build a fully responsive website
- ✅ Ensure cross-browser compatibility
- ✅ Optimize website performance
- ✅ Deploy the project online
- ✅ Prepare complete project documentation
